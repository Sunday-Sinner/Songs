# Sunday Sinner — Songs

Welcome to the official **Sunday Sinner Songs** repository.

This repository contains finished songs created for **Sunday Sinner**, including the audio files, artwork, metadata, and other assets needed to organize and publish the music on the official website.

## 🎵 About Sunday Sinner

**Sunday Sinner** is a music project focused on emotional, dark, raw, and personal songwriting. The music blends elements of emo, alternative pop, R&B, country, and piano-driven songwriting.

The songs in this repository represent completed tracks that are ready to be added to the Sunday Sinner website and, where applicable, released publicly.

## 📁 Repository Contents

Songs may include:

- 🎧 Finished audio tracks
- 🖼️ Song artwork and cover images
- 📝 Song titles and metadata
- 📄 Lyrics and song information
- 🌐 Website-ready assets
- 🔊 Different audio versions when needed

## 🌐 Website

The finished songs stored here are intended to be used on the **Sunday Sinner website**, where listeners can explore the music and learn more about each release.

## 📌 Status

This repository is primarily an archive and content source for **finished songs**.

New songs and supporting assets may be added as they are completed.
